# Emad Norbert Design - Infographics Gallery

موقع عربي جاهز للنشر على GitHub Pages لعرض الإنفوجرافيك.

## طريقة الاستخدام
1. استبدل الصور التجريبية داخل `assets/images` بتصميماتك.
2. افتح `index.html` وعدّل عناوين الكروت وأسماء الصور.
3. ارفع الملفات على Repository في GitHub.
4. من Settings > Pages اختر Branch: `main` ثم Folder: `/root`.

## إضافة تصميم جديد
انسخ كارت من داخل `galleryGrid` في ملف `index.html` وغيّر:
- عنوان التصميم
- القسم `data-category`
- رابط الصورة
- النص الظاهر

الأقسام الحالية:
- biblical
- events
- journeys
- travel
